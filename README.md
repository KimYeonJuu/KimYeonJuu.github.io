# Yeonju Kim · Research Portfolio

Live: https://kimyeonjuu.github.io/

김연주의 양자정보·AI 연구 포트폴리오입니다. 홈은 Kyung-A의 2020 포트폴리오를 참고한 사진 배너와 세 개의 탭으로 구성했습니다. 기존 연구·CV·증빙 상세 페이지는 Ice Bear 디자인을 유지합니다.

## Pages
- `index.html`: `#project` 연구 카드·상세 팝업, `#about` 소개·기술·진로 흐름, `#contact` 연락처
- `cv.html`: 학력, 연구경력, 연구과제, 논문, 수상, 기술
- `journey.html`: 역량을 쌓은 과정과 진로 계획
- `evidence.html`: 논문·수상·활동 증빙 이미지
- `about.html`: 연구 이야기
- `research/`: 각 연구의 방법, 기여, 실험 결과와 증빙

## Maintenance
GitHub Pages: main / (root). Local: `bundle install`, then `bundle exec jekyll serve`.

홈의 기본 탭은 About Me입니다. 탭 주소를 직접 공유할 수 있고 뒤로 가기·새로고침에도 선택 상태가 유지됩니다. 방향키·Home·End로 메뉴를 이동하며, 연구 팝업은 닫기 버튼·Escape·바깥 영역 클릭으로 닫습니다. 팝업을 지원하지 않는 브라우저에서는 기존 상세 페이지가 열립니다.

`assets/portfolio.css`는 홈 디자인, `assets/js/portfolio-tabs.js`는 탭·팝업·배너·메일 주소 복사를 담당합니다. 배너는 일시정지할 수 있고 동작 줄이기 설정을 따릅니다.

논문은 2026.09 게재 승인 상태로 기록하고 공동 기여 표기를 함께 명시했습니다. JCR Top 6.6%는 2025 Engineering, Electrical & Electronic의 JIF percentile 93.4 기준입니다. 양자 연구는 진행 중입니다.
