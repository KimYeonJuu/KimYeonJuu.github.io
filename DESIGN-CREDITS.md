# Layout source

The homepage adapts the HTML structure and selected CSS rules from
[Kyung-A/2020ver-portfolio](https://github.com/Kyung-A/2020ver-portfolio), as requested by the portfolio owner.

- `index.html`: three tabs, Who/Skills profile structure, two featured project cards, three-column record grid, and image/contact panel.
- `assets/kyunga-layout.css`: selected original layout rules, adapted for local assets and typefaces.
- `assets/portfolio.css`: Yeonju Kim's content, responsive adjustments, accessibility and modal styles.
- `assets/js/portfolio-tabs.js`: existing accessible implementation retained for keyboard controls, history, focus, reduced motion and multiple dialogs; original `.btn.on` styling is preserved.

Reference images, the reference author's photograph, personal information and unrelated projects were not copied. Portrait and research evidence belong to this portfolio's owner.

Fonts: SUIT and Passion One (SIL Open Font License); licenses are in `assets/fonts/`.
Skill icons retain the credits in `assets/profile/ICON-CREDITS.md`.
